# 🎬 TMDB API Testing Assignment

A comprehensive **API Testing** project for **The Movie Database (TMDB) API** using **Postman**. This project demonstrates API validation, request execution, response verification, and test automation for RESTful services.

---

## 📖 Project Overview

This project was developed to practice real-world API testing techniques by validating TMDB endpoints using Postman.

The assignment covers functional API testing, response validation, authentication, and automated assertions to ensure API reliability and correctness. TMDB provides REST APIs for retrieving movie, TV show, and actor data through authenticated requests.

## ▶️ Running the Collection

### Clone the repository

```bash
git clone https://github.com/abdo659/TMDB_API_Assignment.git
```

### Import into Postman

1. Import the Postman Collection.
2. Import the Environment file.
3. Add your TMDB API Read Access Token or API Key.
4. Run the requests individually or execute the full collection using the Collection Runner.

You can also execute the collection from the command line using **Newman** if it is included in your workflow.
